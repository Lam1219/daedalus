# Samsung Health Sensor SDK

Put the Samsung Health Sensor SDK `.aar` here (download it from
https://developer.samsung.com/health/sensor after signing in and accepting the license).
`build.gradle.kts` picks up any `.aar` in this folder.

Used for SpO2 and beat-to-beat intervals (breathing-rate estimate) in the session CSV.
Testing on a watch needs Samsung Health "developer mode" turned on there.
